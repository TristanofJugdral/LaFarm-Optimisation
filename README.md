# LaFarm-Optimisation
Timeline of progress surrounding LaFarm farm planning. 

To create your own .html visualisation, run the `RUN_THIS_MATH301_LAFARM.py` file. Your computer may ask you to sign in with Gurobi or allow permissions. 
Ensure all the crop data at the beginning is correct. 
The .csv file is a recorded list of each crop's properties for your reference. Some of these are from the LaFarm dataset, others are researched externally.
